# 投资收益计算器

一个以本地计算为核心的单页投资工具，包含：

- 一次性本金与定期定投的年复利计算
- 买入费率、管理费率、托管费率与销售服务费率的费后收益估算
- 两个日期之间的天数、股价涨跌幅和价格变化计算
- 纳斯达克 100、标普 500、日经 225 与沪深 300 的年度指数数据和复合年化收益率展示
- 纳斯达克 100（VXN）与标普 500（VIX）的近 5 年分位、市场情绪区间和定投金额参考
- 纳斯达克 100（NDX）与标普 500（SPX）的最近交易日收盘点位

VIX、VXN 数据来自 Cboe Global Markets；NDX、SPX 收盘点位来自 Federal Reserve Bank of St. Louis 的 FRED。GitHub Actions 在纽约时间每个工作日 17:30（美股常规收盘后 90 分钟）自动更新，19:17 复查恐慌指数，并在次一交易日 00:30 校验 FRED 指数点位。时区设置为 `America/New_York`，会自动适配美国夏令时和冬令时。数据下载最多重试 4 次；如果收盘数据没有变化，不会产生无意义提交。

网页每次打开都会读取 GitHub 上的最新数据；保持页面打开时，每 15 分钟自动检查一次，重新回到页面且上次检查已超过 5 分钟时也会立即检查。不需要用户下载新的 HTML 文件。

定投参考系数按近 5 年分位分档：`0.75 / 0.90 / 1.00 / 1.20 / 1.50 / 1.75`。这一规则用于约束投入节奏，不预测指数涨跌。

网页入口：`index.html`

> 计算结果、市场情绪和定投金额仅用于数学测算与规则化参考，不构成投资建议。
