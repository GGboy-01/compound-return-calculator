# 投资决策实验室 V10

线上入口：https://ggboy-01.github.io/compound-return-calculator/

## 三个板块
- 指数看板：A股五指数（000680、000688、000698、000699、399006）与美股两指数（NDX、SPX）独立切换。
- 市场情绪：沿用V8·R1的原工具与原数据源。
- 收益工具：沿用复利、涨跌幅与指数收益工具；独立于指数决策。

A股保留本轮高点、旧高点、上轮低点、极端低点；距低点按“从当前还需下降”计算。科创综指固定000680含分红。美股使用滚动近十年历史，将历史回撤深度平移到本轮最高收盘，不用十年前的绝对低点做当前目标。

## 指数数据
- A股历史日线：CSI / CNIndex官方收盘；官方尾部延迟时，仅以东方财富与腾讯同日一致的收盘补齐最新交易日。美股历史统一FRED NASDAQ100、SP500；最新收盘交叉核验，来源与真实日期逐指数保留。东方财富100.NDX并非纳指100，禁止用于该序列核验。
- 初始十年历史审计记录：data/us-history-audit.json。少数FRED/Yahoo差异采用FRED，不混拼盘中价。
- 纳指观察分类10% / 20% / 30%；标普按四轮同历史窗口的跌幅比中位数约0.842换算为8% / 17% / 25%。这是透明的展示分类，未声称最佳买点或收益概率。近十年最大回撤单独展示，恐慌入口不是跌幅上限。
- 看板已移除A股跟踪精度推荐与美股ETF溢价排名。原始研究文件保留作历史记录，不再参与页面渲染或定时更新。

## 收盘更新和部署
GitHub Actions按交易所日历的实际收盘+30分钟确定应到交易日，适配美股夏令时、冬令时、提前收盘及假期。A股15:30首查，15:50、16:10、20:30补查；美股纽约16:30首查，16:50、17:30及次日00:45补查；提前收盘日13:30/13:50检查。

GitHub定时任务可能排队，公开源可能晚到，不能保证恰好目标分钟发布。失败时保留实际收盘及原日期，发布错误状态并使任务失败以提示排查。浏览器每分钟读取已发布数据，不直接跨域抓行情；按钮“读取最新发布数据”也不承诺启动服务端采集。

- data/price-map.json：七指数完整历史和分市场更新状态。
- data/us-etf-rankings.json、data/etf-tracking.json：旧版ETF研究记录，不在看板展示。
- legacy-calculator.html：V8·R1独立工具。
- seed.js：构建时嵌入的带实际日期兜底快照。
